# 추후/제외 항목

## 목적

이 문서는 Android 구현 PRD 본문에 넣지 않은 항목과 그 사유를 기록한다. 본문 PRD는 iOS 현재 구현을 우선하며, 엑셀 명세의 취소선/추후/어드민 항목은 구현 범위로 오인되지 않도록 분리한다.

## 제외 규칙

- 어드민 시트 `어드민-기능명세서(260430 수정완료)`는 제외한다.
- 셀 전체 취소선 기능은 제외한다.
- 셀 일부 문장 취소선은 해당 문장만 제외한다.
- iOS 구현 근거가 없고 추후 고도화로 보이는 기능은 본문에서 제외한다.
- iOS 구현은 있으나 Android UX/정책 결정이 필요한 기능은 본문에 포함하되 `Android Decision Needed`로 표시한다.

## 엑셀 취소선 요약

사용자 시트 기준 213개 기능 중 전체 취소선 기능은 48개, 취소선이 하나라도 포함된 기능은 54개로 확인했다.

대표 제외 항목:

- 홈/커뮤니티/검색 피드의 `공유하기`: 여러 위치에서 취소선 처리 또는 MVP 제거 메모가 있어 본문 핵심 구현 범위에서 제외한다.
- 아티스트 소개 화면 전체: 로그인/비로그인 모두 전체 취소선 처리되어 본문에서 제외한다.
- 알림 삭제/휴지통: `알림 항목 선택`, `전체선택`, `알림 삭제`가 취소선 처리되어 제외한다.
- 게시글 작성의 일부 고도화 기능: 임시저장, 임시저장 목록, 이어쓰기 등은 iOS 현재 구현 근거가 약해 제외한다.
- 마이페이지 일부 부가 기능: iOS 구현 근거가 약하거나 엑셀 취소선 처리된 항목은 본문에서 제외한다.

## 추후/확인 대상으로 분리한 항목

### 회원가입 건너뛰기

- 엑셀에는 비로그인 홈 진입 기능으로 존재한다.
- iOS 현재 온보딩 흐름과 Android 활성 라우트에서 명확한 구현 근거가 약하다.
- Android에서 비로그인 탐색을 앱 시작 단계에서 허용할지 제품 결정이 필요하다.

### 온보딩 관심 아티스트 선택

- iOS는 홈 첫 방문 후 관심 아티스트 선택 화면을 제공한다.
- Android에는 `onboarding/favoriteartist` 구현이 있으나 active nav flow에 연결되지 않았다.
- 본문에서는 홈 첫 방문 `FavoriteArtistSelectScreen` 결정사항으로 다룬다.

### 행사 정보 탭

- 엑셀에는 `행사 정보(오른쪽에서 두번째 탭)`으로 17개 기능이 존재한다.
- iOS에는 `getEvents`, `postEventRefuse`가 있으나 별도 하단 탭/행사 상세 UI 구현 근거와 일치하지 않는다.
- Android 이번 PRD 본문에는 홈 이벤트/배너 범위만 포함하고, 별도 행사 탭은 제품 확인 대상으로 둔다.

### 아티스트 소개 화면

- 엑셀의 로그인/비로그인 아티스트 소개 화면 항목은 전체 취소선 처리되어 본문에서 제외한다.
- Android 구현 중 아티스트 상세 화면이 필요해지면 커뮤니티 기본 정보와 별도 도메인으로 다시 정의한다.

### 공유하기

- 엑셀의 피드/상세 공유하기는 MVP 제거 또는 취소선 처리된 항목이 많다.
- iOS 현재 구현에서 핵심 PRD 범위로 삼을 근거가 부족하므로 제외한다.

### 알림 삭제/휴지통

- 취소선 처리되어 제외한다.
- 알림 조회/읽음 처리는 iOS 구현 근거가 있으므로 `notification.md` 본문에 포함한다.

## 어드민 제외

어드민 시트에는 행사 등록/수정/삭제, 포스터 등록, 예매처, 가격 등 관리자 도구 기능이 포함되어 있다. 이번 산출물은 Android 사용자 앱 구현을 위한 PRD이므로 포함하지 않는다.

## 본문으로 되살리는 조건

아래 중 하나가 확인되면 본문 PRD로 이동할 수 있다.

- iOS 현재 코드에서 대응 화면/ViewModel/API 구현 근거가 확인된다.
- Android 구현 범위로 사용자가 명시적으로 지정한다.
- 서버 API와 제품 정책이 확정되어 Android 구현 태스크로 바로 전환 가능하다.
